Scribe[<sup>[1]</sup>](https://en.wikipedia.org/wiki/Scribe) is a community of language enthusiasts, learners and developers creating tools to help people communicate with confidence.

### Current Projects

- Scribe - Language Keyboards: Packs of phone and tablet keyboards powered by [Wikidata](https://www.wikidata.org/) and [Wiktionary](https://www.wiktionary.org/) with features including translation, verb conjugation and word annotation (see [Scribe-Android](https://github.com/scribe-org/Scribe-Android) and [Scribe-iOS](https://github.com/scribe-org/Scribe-iOS))
- Scribe Conjugate: A verb conjugation app that allows for easy conjugations across multiple languages using data from [Wikidata](https://www.wikidata.org/) (these apps are also maintained in [Scribe-Android](https://github.com/scribe-org/Scribe-Android) and [Scribe-iOS](https://github.com/scribe-org/Scribe-iOS))
- [Scribe-Data](https://github.com/scribe-org/Scribe-Data): A CLI that allows users to easily get language data packs from [Wikidata](https://www.wikidata.org/), [Wiktionary](https://www.wiktionary.org/) and other sources
- [Scribe-Server](https://github.com/scribe-org/Scribe-Server): A [Wikimedia Toolforge](https://admin.toolforge.org/) API to serve language data to Scribe client applications

### Our Community

An official [Wikimedia project for new developers](https://www.mediawiki.org/wiki/New_Developers#Scribe), we strive to be an inclusive community. Be it the software we write or the language data from [Wikidata](https://www.wikidata.org/) and [Wiktionary](https://www.wiktionary.org/) that it's based on, coders and open-source supporters of any level are welcome! Please also [join us in our public Matrix chat rooms](https://matrix.to/#/#scribe_community:matrix.org) to share ideas, ask questions or just say hi :)
